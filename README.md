## Parameters

The shader cycles through the three parameters every 4 seconds (each goes 0 → 1 → 0).

| Parameter | Task | What changes |
| --- | --- | --- |
| `SURPRISE` | Task 1 | Eyes grow, eyebrows rise, mouth opens wider and drops |
| `MISCHIEF` | Task 2 | Left eye winks, right brow arches up, mouth shifts to one side, head tilts |
| `SADNESS` | Extra Credit | Brows slant inward, eyes shrink and lower, mouth shrinks, head bows |
